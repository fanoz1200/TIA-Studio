# حزمة Agent قابلة لإعادة الاستخدام — تطبيق Windows محلي

## الغرض

الملف [`tia-windows-desktop-blueprint.json`](./tia-windows-desktop-blueprint.json) هو **Brief هندسي محايد** يمكن رفعه إلى Agent آخر مع مستودع مشروع جديد. لا ينسخ أسرار TIA Studio أو بيانات عملاء أو مفاتيح اتصال. وظيفته شرح النمط الذي نجح هنا: واجهة ويب محلية، خادم إنتاج مضمّن، وغلاف Electron يقدم Setup وPortable.

> لا ترفق مع هذا الملف أي XER أو XLSX أو مراسلات أو أدلة حقيقية. أعطِ الـAgent عينات مجهّلة فقط، واترك ملفات العميل على جهازه أو مخزن مؤسسي مصرح به.

## كيف تستخدمه مع Agent آخر

| الترتيب | ما ترسله | لماذا |
|---|---|---|
| 1 | المستودع الكامل أو حزمة المصدر اليدوية | لكي يرى الـAgent الاختبارات والبنية الفعلية، لا صورة من الواجهة فقط. |
| 2 | `tia-windows-desktop-blueprint.json` | يحدد معمارية سطح المكتب وحدود الإنتاج وفحوص الإصدار. |
| 3 | المتطلبات الخاصة بالمشروع الجديد | نوع الحسابات، الملفات المسموحة، المنصات المستهدفة، ومقياس النجاح. |
| 4 | نتائج اختبار Windows الحقيقي | هي الدليل الوحيد على نجاح Setup واختصار Start، ولا تستبدلها محاكاة أو بناء ناجح. |

## Prompt قصير اختياري للـAgent

```text
اقرأ ملف tia-windows-desktop-blueprint.json وملفات الاختبار والتغليف في المستودع قبل تعديل أي كود.
ابنِ تطبيق سطح مكتب محلي وفق المعمارية المذكورة، ولا تسمح باستيراد أدوات التطوير مثل Vite في خادم الإنتاج.
أضف اختبارات للمسار الإنتاجي والتغليف، وأنشئ Setup وPortable. لا تدّع نجاح التثبيت إلا بعد اختبار Windows حقيقي.
لا تضع أسراراً أو بيانات عملاء أو ملفات أصلية في Git أو الحزمة أو طلبات AI خارجية.
```

## لماذا لم أسميه Engine واحداً؟

النتيجة ليست مكتبة سحرية واحدة؛ هي **نمط هندسي قابل للتكرار**. محرك الحساب أو مجال العمل يتغير من مشروع لآخر، بينما تبقى طبقات: الحساب الحتمي، الخادم المحلي في الإنتاج، Electron، والتغليف واختبارات الإصدار. فصل الطبقات يمنع تكرار خطأ تشغيل Vite في حزمة Windows.

## حدود مهمة

- Setup غير الموقّع قد يعرض Windows SmartScreen؛ التوقيع الرقمي قرار تشغيل/تكلفة مستقل.
- التطبيق المحلي بعد توزيعه لا يمكن سحب الوصول منه بشكل موثوق؛ استخدم Team Workspace للتحكم في الصلاحيات والمدة.
- هذا النمط لا يثبت صحة حسابات أي نطاق مهني وحده؛ كل محرك يحتاج حالات اختبار ومراجعة اختصاصية مستقلة.
