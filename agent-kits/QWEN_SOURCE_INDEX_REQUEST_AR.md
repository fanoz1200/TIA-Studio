# طلب محدد إلى Qwen — فهرس مصادر فقط لـ Claim Knowledge Base

انسخ النص الآتي إلى Qwen كما هو. لا ترفق أي ملفات مشروع أو XER أو Excel عميل أو مراسلات أو أسماء أطراف.

---

أحتاج **فهرس مصدر قابل للتدقيق فقط** للحالات الـ28 المقترحة لتوسيع مكتبة مطالبات إنشائية. لا أحتاج كوداً، ولا تقرير Claim، ولا رأياً قانونياً، ولا نصوص عقود منسوخة.

أرجو الإخراج كـJSON أو CSV، صف واحد لكل حالة، بالحقول التالية:

| الحقل | المطلوب |
|---|---|
| `proposed_id` | معرف مقترح ثابت، مثل `KB-071` |
| `title_ar` / `title_en` | عنوان مختصر أصلي غير منسوخ |
| `claim_topic` | تأخير، تغيير، تعليق، دفعة، إنتاجية، إلخ |
| `source_type` | كتاب / بروتوكول / حكم منشور / دليل مهني / موقع رسمي |
| `source_citation` | مرجع ببليوغرافي دقيق أو URL عام قابل للفتح |
| `edition_or_date` | الطبعة أو تاريخ النشر إن وجد |
| `jurisdiction_or_contract_context` | السياق فقط، لا تستنتج قابلية التطبيق |
| `short_original_summary` | 40–80 كلمة بصياغتك، بلا نسخ مطول من المصدر |
| `license_or_reuse_status` | عام / مرخص / غير واضح / لا يعاد استخدام النص |
| `dedup_key` | مفتاح مختصر لكشف التكرار |
| `missing_fields` | الحقول أو المصادر التي لا يمكن توثيقها |
| `review_status` | `SOURCED` أو `TO_ENRICH` فقط |

**شروط إلزامية:**

1. لا ترسل نصاً كاملاً من كتاب أو عقد أو حكم محمي بحقوق نشر؛ أرسل استشهاداً ورابطاً وملخصاً أصلياً فقط.
2. لا تستخدم أو تخترع اسم مشروع، عميل، شركة، مبلغ، مراسلة، أو واقعة حقيقية غير منشورة.
3. إذا لم يوجد مصدر مباشر أو ترخيص واضح، اكتب `TO_ENRICH` ولا تملأ بقية الحقول بالتخمين.
4. لا تعتبر أي بند FIDIC أو مهلة Notice قاعدة عامة أو نصيحة قانونية؛ ضع طبعة العقد والسياق، واترك الملاءمة لمراجعة مختص.
5. لا تكتب كوداً ولا تقترح إدخال ملفات العميل إلى نموذج ذكاء اصطناعي.

وفي النهاية أضف جدول Dedup يوضح أي حالات متشابهة أو مكررة محتملة، وما المرجع الذي يجعل كل حالة مميزة.

---

> الناتج المطلوب هو **دليل منشأ** فقط. الدمج في المنتج لن يحدث إلا بعد مراجعة المصدر والترخيص وكشف التكرار محلياً.
