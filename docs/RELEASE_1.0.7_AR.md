# TIA Studio 1.0.7 — تقويم ومراجعة قبل التحليل

## ما أُضيف

هذا الإصدار يوسّع مسار التحليل قبل إنشاء الـ Fragnet، ولا يغيّر ملفات Primavera الأصلية. أضيف تقويم إقليمي يجعل مصر الافتراض المبدئي بستة أيام عمل من السبت إلى الخميس، مع اختيار مصر ودول الخليج ودول عربية أخرى. تعرض الواجهة مصدر الإجازات وتاريخ مراجعتها وتسمح بالمراجعة اليدوية قبل اعتمادها في الحساب.

توجد الإجازات المرتبطة بالتقويم الهجري ضمن قائمة مراجعة، وليست حكماً تعاقدياً تلقائياً. قد تتغير بدايات بعض المناسبات بين الدول أو بقرارات رسمية، لذلك يجب على المستخدم مراجعة التقويم التعاقدي للمشروع قبل اعتماد نتيجة TIA.

أضيفت بوابة جودة مبكرة داخل الرحلة الموجّهة بعد Baseline وPre-TIA Update وقبل إدخال الواقعة أو بناء الـ Fragnet. كما أضيف اختيار متعدد للأنشطة المتأثرة بالبحث أو اللصق من Excel، مع بقاء نقطة ربط كل Fragnet مستقلة وقابلة للمراجعة.

أضيف عارض XER محلي للقراءة فقط لعرض اللقطات المستوردة والأنشطة والعلاقات وWBS والتقويم وفروق النسخ. العارض أداة مراجعة قبل العودة إلى Primavera، وليس بديلاً عنها أو دليلاً على تكافؤ كامل معها. كما أصبح قالب Excel الخاص بالوقائع منظماً ويشمل حقولاً إجبارية واختيارية وقوائم إدخال وتعليمات داخل الملف.

وأصبحت مسودة Notice قابلة للتجهيز والتنزيل محلياً من دون تسجيل دخول، بينما يبقى الحفظ والسجل والمتابعة المشتركة داخل الحساب فقط.

## ما تم التحقق منه قبل التجهيز

بعد إصلاح حزمة Windows، اجتازت المنصة 142 اختباراً في 46 ملف اختبار، وفحص TypeScript وبناء الإنتاج. أضيفت اختبارات تغليف سطح المكتب ضمن المجموعة، مع فحص يمنع أن يحمل خادم الإنتاج Vite وقت تشغيل Windows. كما روجعت واجهات الدليل والموسوعة والرحلة والتقويم وXER وسجل القضايا وNotice على سطح المكتب والهاتف.

## حدود مهنية مهمة

لا يدّعي محرك TIA المحلي تكافؤ Primavera P6. قبل استخدام نتيجة في مطالبة أو قرار زمني، يجب إعادة استيراد ملف التصدير في نسخة غير إنتاجية من Primavera، وتشغيل F9، ومراجعة Calendar وFloat وCritical Path والعلاقات والتقويم التعاقدي. لا تشكّل التقارير أو مسودة Notice حكماً قانونياً أو إثبات استحقاق تلقائياً؛ يلزم مراجعة مختص ومراسلات المشروع الفعلية.

## تحقق Windows المطلوب

ملف Windows Portable الحالي اجتاز فحص بدء محلي داخل بيئة معزولة. يعالج Setup وPortable الحاليان خطأ `Cannot find package 'vite'` الذي ظهر في حزمة 1.0.7 الأسبق عند التشغيل من `%LocalAppData%\Temp`. بُني Setup القياسي بنجاح، لكن لم يكتمل فحص تثبيته داخل Wine بسبب قيود بيئة الاختبار؛ لذلك يظل اختبار المستخدم على جهاز Windows فعلي، بحساب مستخدم عادي ومن دون صلاحيات مسؤول، خطوة تسليم عملية للتأكد من التثبيت وSmartScreen والطابعات وفتح ملفات التصدير.
