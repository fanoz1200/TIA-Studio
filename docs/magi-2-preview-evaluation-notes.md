# ملاحظات أولية — تقييم MAGI-2 Preview

| نوع النموذج | نموذج موحّد لتوليد الفيديو والصوت، ويصدر مقاطع بطول 10 ثوانٍ فقط. | يتوافق زمنياً مع فيديوَي التدريب القصيرين، بشرط نجاح التشغيل. |
| الترخيص | مستودع الكود وبطاقة النموذج يعلنان Apache-2.0. | قابل للاستخدام التجاري من حيث أصل الكود/الأوزان المعلنة، مع الالتزام بنص الترخيص والإشعارات ومراجعة تراخيص التبعيات. |

| الحجم | الأوزان الكاملة تقارب 307 GB؛ وتصف الوثائق مروره بمرحلتين غير مقطرتين بعدد 100 + 5 خطوات. | تنزيل وتجربة تشغيل غير مبرران قبل إثبات توفر الحوسبة الملائمة. |

| الخصوصية | تحسين المطالبة اختياري ويعتمد على نقطة نهاية متوافقة مع OpenAI عند تفعيله؛ يمكن تجاوزه. | أي تشغيل مستقبلي يجب أن يبقي التحسين مغلقاً أو يمرره عبر خدمة يوافق عليها المستخدم، ولا يرسل ملفات P6 أو Excel. |
| الاستدلال المستضاف | بطاقة النموذج تفيد بأنه غير منشور لدى أي مزود استدلال على Hugging Face وقت المراجعة. | لا يوجد مسار استدعاء مستضاف جاهز وموثوق يمكن ربط التطبيق به فوراً. |
| زمن الإنتاج | لم تنشر الوثائق الرسمية زمناً معيارياً لكل مقطع؛ وهي تؤكد 100 خطوة للمرحلة التمهيدية و5 للمُنقّح، وأن المرحلة غير مقطرة. | لا يمكن تقديم وعد زمني موثوق لمقطع 10 ثوانٍ قبل اختبار قبول على عتاد مطابق. |
| سلسلة التوريد | صورة Docker الرسمية مبنية على NVIDIA PyTorch وتستنسخ `flash-attention` وMagiAttention وMagiCompiler عند مراجعات مثبتة، بينما يحوي ملف المتطلبات بعض الحدود الدنيا غير المثبتة. | التشغيل الآمن مستقبلاً يكون بصورة Docker ذات وسم commit ثابت، مع فحص SBOM/الثغرات وتثبيت حزم الإنتاج، داخل حاوية معزولة. |

## نتيجة فحص البيئة المحلية

أظهر فحص بيئة العمل الحالية غياب `nvidia-smi` و`nvcc` وDocker، مع 37 GB فقط من المساحة المتاحة وذاكرة RAM متاحة تقارب 20 GiB. لذلك لا تتوافر وحدات GPU من فئة Hopper ولا CUDA ولا مساحة كافية حتى لتنزيل الأوزان الرسمية (نحو 307 GB). تفاصيل الفحص محفوظة في `docs/magi-2-local-environment-check.txt`.
