# مراجع الفيديو الخارجي التي راجعها TIA Studio

## قائمة تعليمية اختيارية: Project Delay Analysis in Primavera P6

الرابط: https://www.youtube.com/playlist?list=PLGmHUMIVgQ3V-mzo4d8laPbzXI0ltjdEB

راجعت القائمة في 18 أغسطس 2026. وهي قائمة عامة من ثمانية فيديوهات باللغة الإنجليزية حول تحليل التأخير في Primavera P6، وتشمل نظرة عامة على المنهجيات، **As Planned vs As Built**، و**Fragnet**، و**Impacted As Planned**، و**Collapsed As Built**، و**Time Impact Analysis (TIA)**، و**Windows Analysis**، و**Concurrent Delay**.

يظهر الرابط في مركز الفيديو داخل التطبيق كمصدر تدريبي خارجي اختياري فقط. لا يشكل محتواه دليلاً فنياً أو تعاقدياً، ولا يغني عن تحقق المستخدم من العقد، وإصدار البرنامج، والبيانات، ومنهجية التحليل المناسبة للواقعة.
