# الدليل الحيّ للنسخة المحلية — TIA Studio 1.0.1

## الغرض من هذا الدليل

هذا الدليل جزء من الإصدار نفسه، وتظهر نسخة مختصرة منه داخل تبويب **مركز المعرفة والتنزيل**. وهو يشرح ما الذي يحسبه التطبيق، وكيف تنتقل البيانات بين أقسامه، وما الذي يجب مراجعته قبل إصدار أي تقرير أو ملف تبادل. لا يستبدل هذا الدليل العقد أو الحكم المهني أو برنامج Primavera.

| عنصر الإصدار | الحالة |
|---|---|
| رقم الإصدار | 1.0.9 |
| تاريخ التوثيق | 24 أغسطس 2026 |
| محرك الحساب | CPM/TIA حتمي محلي داخل التطبيق |
| أنظمة سطح المكتب | Windows x64 وLinux x64 |
| نقطة التشغيل | EXE واحد في Windows أو AppImage واحد في Linux |

## خريطة المنهجيات

> **TIA:** يقارن التطبيق نسخة Pre-TIA مستقلة بنسخة Post-TIA بعد إدراج Fragnet مرتبط بحدث محدد؛ ولذلك فإن النتيجة مرتبطة بالمنطق والمدد المدخلة وليست توقعاً أو حكماً قانونياً آلياً.

| المنهج | متى يستخدم | الضابط داخل البرنامج |
|---|---|---|
| Time Impact Analysis | يوجد برنامج أساس أو تحديث مناسب قبل الحدث ويمكن تعريف Fragnet | نسخ Pre/Post منفصلة، تشغيل CPM، تحقق نتيجة TIA |
| Windows & Concurrency | توجد تحديثات متتابعة أو أحداث متزامنة | نوافذ زمنية، إشارات تزامن، مراجعة المسؤولية لكل حدث |
| بوابة جودة GAO/AACE | دائماً بعد الاستيراد وقبل التحليل | قبول وتحذير ومانع مع سجل تحسين محلي |

## المحركات وترابطها

| المحرك | مدخلاته | مخرجاته | من يعتمد عليه لاحقاً |
|---|---|---|---|
| قارئ P6 | XER أو XML | أنشطة وعلاقات وWBS وموارد ومعرف تقويم لكل نشاط، مع سجل قيود | الجودة وCPM والمقارنة |
| CPM | أنشطة وعلاقات وتقويم جدول مختار وقيود سفلية موثقة فقط | ES/EF/LS/LF وFloat ومسار حرج محلي | TIA والتحقق والتقرير |
| Fragnet | واقعة ونقاط ربط | Post-TIA أو تقسيم Pre/Event/Post | CPM وTIA |
| جودة الجدول | نسخة مستوردة | قبول/تحذير/مانع | اعتماد Pre-TIA وبوابة التصدير |
| تحقق TIA | نتائج قبل/بعد | قرار قابلية الاستخدام | التقرير وExcel وXER التجريبي |
| التصدير | نتيجة معتمدة وأدلة | Word/PDF/Excel/XER تجريبي | المراجعة الخارجية |

## سير العمل العربي المعتمد

ابدأ بالبحث في الموسوعة أو سجل القضايا، ثم ارفع Baseline والتحديث السابق للحدث. بعد الاستيراد، راجع الجودة ولا تعتمد Pre-TIA عند وجود مانع. إذا ظهر أكثر من تقويم نشاط، أو قيد XER غير مدعوم، أو تقويم P6 مشفر لم يُفك، يوقف التطبيق الاعتماد المحلي حتى تراجع ذلك في Primavera. يدعم الحساب المحلي فقط **Start On or After (CS_SNET)** و**Finish On or After (CS_FNET)** كحدود دنيا، وعلى تقويم الجدول المختار لا على تقويم النشاط المشفر. أدخل الواقعة والأدلة، ثم أنشئ Fragnet وحدد نقاط الربط أو قسم النشاط المتأثر. شغّل التحليل وراجع النتيجة، ثم استكمل الأثر المالي وNotice والاعتماد قبل التصدير.

| مرحلة | نقطة التحقق | القرار التالي |
|---|---|---|
| الاستيراد | عدد الأنشطة والعلاقات والتقويم والتحذيرات | الانتقال للجودة أو إعادة الاستيراد |
| الجودة | لا يوجد مانع منطقي | اعتماد Pre-TIA أو إصلاح البرنامج |
| Fragnet | مدة محددة وربط مفهوم وأدلة | تشغيل TIA أو تعديل النموذج |
| النتيجة | فرق تاريخ الإكمال ومؤشرات التزامن | متابعة التقرير أو إعادة الفرضية |
| التصدير | بوابة التحقق ناجحة | Word/PDF/Excel وXER تجريبي ضمن الحدود |

## سياسة تحديث الدليل

عند تغيير أي منطق في قارئ P6 أو CPM أو Fragnet أو التحقق أو التصدير، يجب تحديث رقم الإصدار، وسجل التغييرات، والصف المقابل في هذا الدليل، وإعادة الاختبارات والبناء قبل إتاحة رابط التنزيل. لا تُحذف الإصدارات القديمة من السجل؛ تبقى للمراجعة مع تاريخها وحدودها.

## سجل التغييرات

### 1.0.9 — 24 أغسطس 2026

أضاف هذا الإصدار تدقيقاً صريحاً لتقاويم الأنشطة وقيود XER: يحفظ `clndr_id` لكل نشاط، ويعرض تعدد التقاويم كمانع مراجعة لأن أنماط ساعات P6 والاستثناءات لم تُفك بعد. تُستورد قيود `CS_SNET` و`CS_FNET` فقط كحدود دنيا في CPM المحلي؛ أما القيود الصلبة أو العلوية أو الثانوية أو غير المعروفة فتظل أدلة مراجعة ولا تدخل الحساب. لا يحقق هذا المحرك تعادلاً مع إعادة جدولة Primavera أو F9، ولا يطبق بعد Progress/Remaining Duration كتحديث P6.

### 1.0.1 — 20 أغسطس 2026

أضاف هذا الإصدار دليلاً حيّاً داخل البرنامج يشرح المنهجيات والمحركات والعلاقات وسير العمل. كما ثبّت قاعدة تنزيل محلية واضحة: ملف EXE محمول واحد لمستخدمي Windows وملف AppImage واحد لمستخدمي Linux، مع تعليمات تشغيل مباشرة في مركز الموارد.
