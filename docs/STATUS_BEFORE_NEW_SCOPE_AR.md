# حالة TIA Studio قبل نطاق جديد

**الإصدار المرجعي الحالي:** `1.0.7`  
**حالة الحزمة:** Windows Portable وLinux AppImage وأرشيف مصدر مستقل متاحون.  
**قاعدة العمل:** حسابات CPM/TIA حتمية ومحلية؛ لا يستخدم التطبيق نموذج ذكاء اصطناعي لاتخاذ نتيجة CPM أو TIA أو استحقاق تعاقدي.

> يفرّق هذا التقرير بين ما تم اختباره، وما هو حد تقني معلن، وما يحتاج تحققاً يدوياً داخل Primavera P6 Professional 23.12. لا ينشئ حالات أو نتائج غير موجودة في المصادر المرفوعة.

## ما اكتمل فعلياً

| المحور | ما تم إنجازه | حالة الإثبات |
|---|---|---|
| محرك البرنامج | استيراد XER محلي للأنشطة والعلاقات وWBS والموارد المتاحة، مع CPM وFragnet وTIA حتمي. | اختبارات انحدار وبناء إنتاج ناجحان قبل تثبيت الحزمة. |
| التقويم | مصر افتراضياً ستة أيام عمل السبت–الخميس، مع دول خليجية وعربية واختيار مصدر الإجازات ومراجعته يدوياً. | اختبارات تقويم وتحميل محاكاة. الإجازات الهجرية والترحيلات للمراجعة. |
| بوابة الجودة | خطوة إلزامية بعد Baseline وUpdate وقبل Excel أو Fragnet، تراجع الأنشطة والعلاقات وData Date والتقويم. | اختبارات رحلة موجّهة. |
| سجل الوقائع | بحث واختيار متعدد ولصق Activity IDs؛ قرار ربط كل Fragnet مستقل. | اختبارات واجهة ووحدة. |
| عارض XER | قراءة محلية للنسخ والأنشطة والعلاقات وWBS والتقويم والفروق. | اختبار واجهة؛ ليس Primavera. |
| Excel وNotice | قالب وقائع منسق بقوائم وتحقق وتعليمات، ومسودة Notice محلية قابلة للتنزيل دون تسجيل دخول. | اختبارات Blob وExcel. |
| التشغيل المحلي | حزم 1.0.7 ومصدر المشروع؛ Windows EXE استجاب في Wine/Xvfb على 4317. | تحقق إقلاع معزول؛ ما زال فحص Windows فعلي مطلوباً. |

## عينة Workshop المحلية

| القياس | Baseline | Post-TIA | الفرق المحلي |
|---|---:|---:|---:|
| النشاطات المقروءة | 9 | 13 | +4 |
| العلاقات المقروءة | 9 | 15 | +6 |
| عناصر WBS | 3 | 3 | 0 |
| التقاويم | 1 | 1 | 0 |
| مدة CPM المحلية | 80 يوم عمل | 97 يوم عمل | **+17 يوم عمل** |

فرق +17 يوم في العينة تدقيق بنيوي ومحلي فقط. ليس دليلاً على تطابق إعدادات Primavera أو القيود أو الاستثناءات التقويمية.

## ما لا يزال مفتوحاً

| البند | الحالة | الإجراء الصحيح لاحقاً |
|---|---|---|
| تحقق P6 23.12 المكافئ | مراجعة يدوية لازمة | استيراد مصادر/مخرجات غير إنتاجية وتشغيل F9 ومقارنة التقويم والنهاية والـfloat والمسار الحرج. |
| التصدير العكسي إلى P6 | تجريبي | لا تستخدمه في مشروع حي قبل اختبار استيراد يدوي في P6 غير إنتاجي. |
| الحالات D-056 إلى D-088 | غير متاحة | لا تضاف إلا من مصدر منظم وموثق. |
| فيديو رفع P6 وExcel | مؤجل | ينتج ويراجع عند توفر وسيلة معتمدة، ولا توجد فيديوهات منشورة حالياً. |
| النسخ الاحتياطي | مؤجل بطلب المستخدم | يحدد لاحقاً بعد اتفاق على جهة التخزين وسياسة حفظ الأسرار والبيانات. |
| تجربة Windows حقيقية | لازمة | اختبار EXE بحساب عادي، SmartScreen والحماية والطباعة وملفات التصدير على جهاز المستخدم. |
