# دليل إصدار وتشغيل سطح المكتب — TIA Studio

## الغرض الحقيقي من نسخة سطح المكتب

هذه النسخة تغلف منصة **TIA Studio** داخل تطبيق سطح مكتب Electron. يبدأ التطبيق خادماً محلياً على العنوان `127.0.0.1` فقط، ثم يفتح الواجهة في نافذة مستقلة. لا يفتح المنفذ على الشبكة المحلية، ولا يمنح واجهة المستخدم صلاحية مباشرة لتنفيذ أوامر نظام التشغيل.

> **حدود صريحة:** يعمل استيراد ملفات XER/XML، الحساب المحلي لـ CPM/TIA، بوابة جودة الجدول، المشاريع التدريبية، وتصدير Word/PDF/Excel داخل النسخة المحلية. أما تسجيل الدخول، الدعوات، قاعدة البيانات المشتركة، التخزين السحابي، والإشعارات فتحتاج خدمة المنصة وبيانات اعتماد صحيحة، ولذلك لا تُعتمد أثناء العمل دون اتصال.

## الإنشاء على جهاز تطوير

يتطلب الإنشاء Node.js 22 أو أحدث وpnpm. من جذر المشروع نفّذ:

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm desktop:pack
```

ينتج الأمر الأخير حزمة **Linux AppImage x64** في مجلد `release/`. يجب اختبار الحزمة على جهاز منفصل أو حساب مستخدم جديد قبل توزيعها، وفتح مشروع تدريبي مصطنع ثم استيراده وفحصه وتشغيل TIA وتصدير التقرير وملف Excel. لا يعتبر الملف صالحاً لمشروع فعلي قبل هذه الجولة.

## سلامة التشغيل المحلي

لا تضع ملفات مشاريع فعلية داخل حزمة الإصدار، ولا تضف أسراراً أو ملفات `.env` إلى التنزيل. يبقى ملف P6 الأصلي للقراءة فقط؛ أما ملف XER الصادر من الأداة فهو **تجريبي محدود النطاق** ويجب أن يمر بالتحقق العكسي داخل التطبيق ثم اختبار استيراد يدوي في نسخة Primavera غير إنتاجية قبل استخدامه في أي برنامج حقيقي.

## تحديث الإصدارات

كل إصدار جديد يبدأ باختبارات `pnpm test` وبناء `pnpm build`، ثم يحصل على رقم إصدار وتغيير موثق. التحديث ليس تلقائياً في هذه النسخة؛ يحمل المستخدم ملف الإصدار الجديد من مركز الموارد ويحتفظ بنسخة المشروع الأصلية وتقارير الإصدار السابق للمراجعة.
