# ملاحظات مراجعة الواجهة — 23 أغسطس 2026

راجعت الواجهة على سطح المكتب بعد إضافة دليل الاستخدام المصوّر وبداية الموسوعة التفاعلية. الدليل يعرض لقطة حقيقية من كل خطوة، وبطاقات خريطة النوافذ ظاهرة بوضوح، وزر بدء التحليل داخل الدليل واضح. بداية الموسوعة أصبحت ثلاثة مداخل بدلاً من عرض كل الجداول دفعة واحدة، وتظهر أسئلة شجرة القرار وزر فتح المسار المقترح.

مسار التحليل يوضح ترتيب Workshop 8 بخطوات مرئية. ما زال مطلوباً تحسين تفسير شروط الانتقال عند غياب Baseline أو Update أو واقعة، حتى لا يفسر المستخدم رسالة المنع على أنها زر غير عامل.
