# خيارات النسخ الاحتياطي المستقل

## ما هو محفوظ بالفعل

المصدر المتعقب موجود في GitHub، وحزم Windows الرسمية موجودة في GitHub Releases، ويوجد مولد يدوي لحزمة استمرارية خارج مجلد المشروع: `pnpm continuity:package`. لا تحفظ هذه المسارات تلقائياً ملفات العملاء الخام أو الأسرار أو محتوى المحادثة غير المصدَّر، وهذا مقصود لحماية البيانات.

لا تعدّ الوجهة النسبية مثل `./Master_Claim_Intelligence_V3/Backups` نسخة مستقلة: فهي تقع تحت نفس المشروع أو نفس القرص المحتمل أن يتعطل أو يحذف. ولا يُشغّل النسخ الدوري من بيئة مؤقتة لأنها ليست مخزناً دائماً.

## الخيارات المتاحة

| الخيار | ما يُحفظ | المقابل | التكلفة | صعوبة الإعداد |
|---|---|---|---|---|
| **A — GitHub + قرص خارجي مشفر** | المصدر من GitHub، وحزمتا Windows وملف SHA-256، وحزمة الاستمرارية على قرص USB/SSD منفصل | خطوة يدوية واضحة بعد كل إصدار أو أسبوعياً؛ لا مزامنة تلقائية | لا تكلفة خدمة إضافية غالباً | منخفضة |
| **B — GitHub + سحابة يملكها المالك** | نفس محتوى A إلى Google Drive أو OneDrive أو S3/Backblaze في حساب المالك | يمكن تشغيل رفع دوري بعد توفير وجهة ومفتاح/تفويض مناسبين؛ يحتاج اختبار استعادة | حسب السعة ومزود التخزين | متوسطة |
| **C — مستودع خاص ثانٍ للمرايا** | مرآة source فقط في GitHub خاص أو GitLab، بجانب مستودع العمل وحزم Releases | يحمي الكود من خطأ المستودع الأول، لكنه لا يكفي وحده لملفات العميل أو حزم التشغيل | غالباً مجاني ضمن الحدود | منخفضة إلى متوسطة |

## نطاق النسخة الآمنة المقترح

يحفظ النسخ الدوري الافتراضي ملفات Git المتعقبة، وتوثيق البناء، وmanifest، وSHA-256، وحزم Windows المنشورة. يستبعد نهائياً ملفات العميل الخام (XER/XML/XLSX والأدلة)، مفاتيح البيئة، قواعد البيانات، والمجلدات المؤقتة، إلا إذا اختار المالك وجهة مشفرة وسياسة احتفاظ منفصلة لهذه الملفات.

## اختبار الاستعادة

لا يكفي نجاح الرفع. أول دورة معتمدة يجب أن تستعيد الحزمة في مجلد جديد، وتتحقق من `SHA-256`، وتشغّل `pnpm install --frozen-lockfile` ثم `pnpm test` و`pnpm build`. ويؤكد المستخدم تشغيل ملف Windows من النسخة المنسوخة على جهازه عند أول إصدار.

## قرار مطلوب من المالك

اختر **A** أو **B** أو **C**. إذا اخترت B، حدد المزود والحساب/المجلد المخصص؛ بعدها فقط يمكن تصميم التنفيذ الدوري وتفويضه، مع سجل نجاح وفشل واختبار استعادة. يبقى GitHub Release مسار تنزيل وليس بديلاً عن نسخة احتياطية لبيانات العميل.
