# تحقق بصري: مركز الموارد وتنزيل سطح المكتب

**تاريخ التحقق:** 19 أغسطس 2026  
**بيئة التحقق:** نسخة التطوير المحلية للتطبيق، شاشة سطح مكتب 1280×720.

## ما تم التحقق منه

ظهر تبويب **الأدلة والملفات** ضمن التنقل الرئيسي، وفتح بطاقة **مركز المعرفة والتنزيل** دون إخفاء مسار TIA أو تغيير حالة البرنامج التجريبي. ظهرت بطاقة الاستخدام المحلي، وحزمة المصدر، ونسخة Windows المحمولة، ونسخة Linux AppImage في بطاقات مستقلة ذات روابط تنزيل واضحة.

| العنصر | الحالة الظاهرة | القيد المعروض للمستخدم |
|---|---|---|
| حزمة المصدر | ظاهر مع رابط تنزيل | يلزم تثبيت الاعتمادات واتباع دليل التشغيل المحلي |
| Windows x64 Portable | ظاهر مع رابط تنزيل | غير موقّعة رقمياً؛ تُفحص أمنياً وتُجرب بملف تدريبي أولاً |
| Linux x64 AppImage | ظاهر مع رابط تنزيل | يمنح الملف صلاحية تنفيذ ويُختبر بملف تدريبي أولاً |
| وضع الاستخدام المحلي | ظاهر | الحساب المحلي للـ CPM/TIA وقراءة XER/XML متاحان؛ الحسابات والأدلة والاعتمادات المحفوظة تحتاج الخادم |

## الحكم

الواجهة تعرض الحزم والحدود بصياغة متوازنة ولا تدّعي أن النسخة المكتبية بديل عن مراجعة مهنية أو اختبار استيراد Primavera على بيئة غير إنتاجية.
