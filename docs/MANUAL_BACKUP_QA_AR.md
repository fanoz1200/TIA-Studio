## فحص حدود الخصوصية

فُحصت قائمة أرشيف المصدر بعد إنشائه. لم تتضمن أي مسار داخل `.review-extract` أو أي ملف بالامتدادات التالية: `.xer` و`.xml` و`.xls` و`.xlsx` و`.doc` و`.docx` و`.pdf`.

تحمي قواعد `export-ignore` أرشيف `git archive`، كما حُذف ملف XER التدريبي الخام من الشجرة المتعقبة وحُوّل إلى fixture نصي مصغّر داخل اختبار المستورد. لا تُغني هذه القواعد عن مراجعة صاحب المشروع قبل وضع ملفات جديدة في Git.

تضمنت العينة ملفي Windows المتاحين محلياً للإصدار `1.0.12` (Setup وPortable)، وتحققت بصماتهما داخل `SHA256SUMS.txt`. لكن **لا يُدّعى تطابقهما البرمجي مع commit المصدر أعلاه**؛ يلزم إعادة بناء الحزمتين من ذلك المصدر واختبارهما على Windows لإثبات هذا التطابق.
