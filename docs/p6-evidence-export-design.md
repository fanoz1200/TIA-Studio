# تصميم توسعة P6 والأدلة والتقارير

## نطاق الاستيراد المعتمد

يدعم محول P6 داخل TIA Studio قراءة المشروع والأنشطة والعلاقات وهيكل تقسيم العمل (WBS) والتاريخ المرجعي ونسب الإنجاز من ملفات **XER** و**Primavera XML**. تمثل الأنشطة بخصائصها التخطيطية وبالنسبة المعلنة في ملف المصدر؛ ولا يعيد التطبيق احتساب Earned Value أو يستبدل برنامج P6 الأصلي. تقبل طبقة XML أسماء عناصر P6 الشائعة بمرونة، وتعرض رسالة تدقيق عند غياب تاريخ أو مدة أو مرجع WBS.

|عنصر التحويل|الوجهة في TIA Studio|قاعدة المعالجة|
|---|---|---|
|Project / TASK|اسم البرنامج والأنشطة|يستخدم معرف النشاط ومدة باقية أو مدة مستهدفة، مع الاحتفاظ بملاحظة مصدرية|
|PROJWBS / WBS|مسار WBS متدرج|يبنى من العلاقة الأب–الابن، ثم يربط بكل نشاط بحسب معرف WBS|
|TASKPRED / Predecessor|علاقات CPM|يحوّل FS/SS/FF/SF والـlag المتاح|
|Percent Complete|`percentComplete` و`percentCompleteType`|يعرض كنسبة معلنة من P6 ولا يغيّر منطق CPM أو الاستحقاق|
|Calendars|تقويم المشروع|يقرأ الاسم/المعرف عند توافرهما؛ تظل أنماط P6 الثنائية أو المشفّرة بحاجة مراجعة بشرية|

> «تتضمن ملفات XML وXER المشاريع والبيانات المرتبطة بها فقط إذا كانت معينة صراحة للمشروع أو أنشطته.» [1]

## تصميم الأدلة

تُرفع المرفقات إلى تخزين كائنات آمن، بينما تحفظ قاعدة البيانات بيانات التعريف فقط: اسم الملف، نوعه، حجمه، مفتاح التخزين، الرابط، تاريخ الاستلام، وصف الدليل، والحدث المرتبط. لا تحفظ بايتات الملفات في قاعدة البيانات. يتطلب الرفع مستخدماً مسجلاً حتى تُعزل الأدلة بحسب مالك الحساب.

## تصميم التقرير

يُبنى التقرير من بيانات TIA، السرد التحليلي، سجل الأحداث، وملحق الأدلة. يحتوي قالب المطالبة القابل للتعديل على العنوان والجهة المتلقية ومرجع العقد والمقدمة وطلبات المطالبة والخاتمة. ينتج التصدير **DOCX** فعلياً و**PDF** على المتصفح، ولا يرسل محتوى التقرير لخدمة خارجية.
