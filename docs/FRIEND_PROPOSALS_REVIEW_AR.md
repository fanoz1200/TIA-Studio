# مراجعة اقتراحات التطوير وخطة التنفيذ الآمن

> **الحالة:** مراجعة تصميمية — 24 أغسطس 2026.  
> **قاعدة ثابتة:** TIA Studio يساعد في تنظيم الدليل والحساب الفني المحلي؛ لا يقرر أهلية EOT أو التعويض أو سقوط الحق أو صحة جدول Primavera من تلقاء نفسه.

## الحكم المختصر

الاقتراحات مفيدة، خصوصاً فكرة **بوابة جودة قابلة للتدقيق**، و**تنظيم الـ Fragnet**، و**إخراج Word/Excel**، و**حفظ لقطات البرنامج**. لكن بعض الجمل المقترحة تحتاج تصحيحاً قبل تحويلها إلى كود: تقويم الـ Fragnet لا يفرض من نوع الحدث وحده، ومهلات FIDIC لا تُفترض من أرقام ثابتة، وظهور التزامن لا ينتج تلقائياً «EOT بدون تكلفة»، ولا تعني نتيجة DCMA أو SCL حكماً قانونياً.

| المقترح | التقييم | القرار العملي في TIA Studio |
|---|---|---|
| WBS وترقيم Fragnet تلقائي | مفيد كتنظيم | يضاف كـ **اقتراح قابل للتعديل**: Prefix/Activity IDs وWBS دليلية، ولا يستبدل اختيار المهندس للعلاقات أو التقويم. |
| فرض تقويم 5/7 أيام من نوع التأخير | غير آمن كقاعدة عامة | لا يُفرض. التقويم المختار يجب أن يبقى واضحاً ومراجعاً مقابل برنامج المشروع والعقد والحدث؛ وحالياً تعدد تقاويم P6 ما زال blocker معلناً. |
| Float → Critical → EOT | غير صحيح كاستنتاج آلي | يعرض البرنامج float/critical path الحسابيين مع مصادر وحدود. لا يحوّل ذلك إلى قرار استحقاق EOT. |
| DCMA 14-Point | أولوية متوسطة ومناسبة | يوسّع تدريجياً بوابة الجودة الحالية؛ كل قاعدة تعرض البيانات والحدود، وليست قفلاً قضائياً عاماً. |
| Hudson/Eichleay/Measured Mile | مفيد لكن يحتاج بيانات مستقلة | يؤجل لمحرك مالي منفصل: مدخلات موثقة، وحدة عملة، مصادر إنتاجية، نسخة معادلة، وتحفظ ظاهر. لا يخرج مبلغ مطالبة أو توصية مالية تلقائية. |
| FIDIC Notices 28/84 يوماً تلقائياً | يحتاج عقداً وإصداراً وواقعة | يستمر Tracker القابل للضبط من المستخدم مع مصدر مرجعي. لا تُفرض مدد FIDIC افتراضية. |
| Windows/Concurrency وDominant Delay | ذو قيمة فنية | يبقى سجل التزامن والنوافذ أدوات توثيق ومراجعة. يتطلب تنفيذ Windows كامل بيانات updates وData Date وتقويمات ومنهجية تحقق قبل أي نتيجة. |
| Snapshots Baseline/Update/Impacted | مبدأ صحيح | يستمر حفظ اللقطات التحليلية وعدم overwrite للأصل. يجب أن تبقى الملفات الحساسة محلية ولا تدخل مستودع GitHub أو خدمة خارجية. |
| Retained Logic / Progress Override | فجوة صريحة | لا يدّعى دعمهما. لا ينفذ CPM المحلي F9/Data Date أو إعادة جدولة P6 للـActuals/Remaining حتى وجود fixtures مرجعية واختبار P6 غير إنتاجي. |
| Word/PDF/Excel وNotice | قيد التنفيذ ومتاح جزئياً | Word وFact Pack وExcel موجودة. يضاف اختيار لغة صريح للقوالب والمخرجات، لكن لا تترجم الأداة تلقائياً وقائع المستخدم أو أدلته. |
| 20-Point Final Checklist | أولوية أمان مرتفعة | بعد اللغة، تضاف كقائمة مراجعة قابلة للتتبع تمنع **التصدير الخارجي النهائي فقط عند اختيار العميل هذا السلوك**؛ ولا تمنع حفظ مسودة أو العمل التعليمي. |

## دعم العربية والإنجليزية

### ما سيُنفذ الآن

1. إعداد واحد ظاهر في الواجهة لاختيار **عربي** أو **English** وحفظه محلياً على الجهاز.
2. اختيار منفصل للغة كل مخرج: **Arabic** أو **English** في Delay Narrative وFull Claim وNotice وFact Pack، بدلاً من ربط لغة الملف بلغة الواجهة بالقوة.
3. القوالب والعناوين والتحفظات النظامية تُنشأ باللغة المختارة وباتجاه الصفحة الصحيح (`RTL` للعربية و`LTR` للإنجليزية).
4. تظل أسماء الأنشطة، وصف الحدث، الأدلة، والملاحظات التي كتبها المستخدم كما كتبها؛ لا تُترجم تلقائياً ولا تُرسل إلى نموذج خارجي. إن احتاجت مطالبة ثنائية اللغة، يراجع المستخدم النصين ويصدر ملفين منفصلين.

### ما لن يُدّعى تنفيذه دفعة واحدة

الواجهة الحالية عربية وفيها مكونات كبيرة عديدة. سيتم وضع إعداد اللغة والبنية المركزية وقوالب المخرجات أولاً، ثم تُترجم الشاشات بالتتابع مع اختبارات. لا يقال إن كل عنصر قديم صار إنجليزياً قبل أن يغطيه اختبار ومراجعة شاشة فعلية.

## المراجع

1. [SCL — Delay and Disruption Protocol](https://www.scl.org.uk/resources/delay-disruption-protocol): بروتوكول إرشادي يركز على شفافية البيانات والمنهجية، وليس حكماً آلياً على استحقاق فردي.
2. [DAU — Schedule Health Analysis](https://content1.dau.edu/EVM263-schedule-health-analysis-raw_93/content/): فحوص DCMA مهمة لكنها ليست كل مؤشرات الصحة ولا ينبغي التعامل معها كـgo/no-go مطلق.
3. [AACE — RP 29R-03 overview](https://communities.aacei.org/events/event-description?CalendarEventKey=639aaea0-ab07-491a-8caa-018ad7ddd3a8&hlmlt=ED): مرجع إرشادي يتطلب حكماً مهنياً ولا يطبق كقاعدة جامدة.
