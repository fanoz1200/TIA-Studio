# دليل المستخدم وسير العمل — TIA Studio

> اتبع هذا الدليل بالترتيب. لا تنتقل من بوابة إلى التالية إذا أظهر التطبيق تحذيراً لم تعالجه أو إذا لم يكن لديك برنامج مرجعي واضح.

## أ. التحضير قبل فتح التطبيق

اجمع نسخة البرنامج المعتمدة أو آخر تحديث موثوق، وملف XER أو P6 XML، والتقويم والعطل، وسجل الأحداث، ومستندات مثل المراسلات والتعليمات والرسومات. اكتب تاريخ العلم بكل حدث وبند العقد الذي يحكم الإشعار. لا تستخدم ملفاً بعد تغيير منطقي غير موثق باعتباره خط أساس.

## ب. الدورة اليومية للتحليل

| رقم | ما تفعله في التطبيق | تحقق قبل المتابعة | علامة القبول |
|---|---|---|---|
| 01 | افتح «البرنامج والتقويم» واستورد الملف | نوع الملف، عدد الأنشطة، عدد العلاقات | لا توجد رسالة حلقة منطقية |
| 02 | راجع التقويم والعطل | أيام العمل ومصدر التقويم وتاريخ البيانات | الإكمال الأساسي منطقي للمشروع |
| 03 | افتح «نمذجة Fragnet» | اختر علاقة حقيقية وحدد سبب ومدة الحدث | الحدث مربوط بدخول وخروج واضحين |
| 04 | اضغط «تشغيل التحليل» | راجع فرق الإكمال والمسار الحرج والعائمة | نتيجة قابلة للتفسير وليست صفراً غير مفسر |
| 05 | افتح «نوافذ وتزامن» عند الحاجة | نطاق النافذة والأحداث المتداخلة | قضايا التزامن موضحة للمراجع |
| 06 | افتح «الأثر المالي» | الموارد ضمن نطاق الحدث وتحذيرات المطابقة | لا تستخدم قيمة بها تحذير دون تفسير |
| 07 | أرفق الأدلة | عنوان ووصف ونوع وربط الحدث | كل واقعة رئيسية لها دليل أو ملاحظة غياب |
| 08 | افتح «سجل Notices» | تاريخ العلم وموعد الإشعار والبند والمستلم | المسودة مكتملة قبل تغييرها إلى «مرسل» |
| 09 | افتح «الاعتماد الإلكتروني» | عيّن مراجعي التخطيط والعقود ومدير المطالبات | المراجع الصحيح في كل بوابة |
| 10 | افتح «السرد والتقرير» | النتيجة والنص والماليات والـ Notice والاعتماد | صدّر DOCX/PDF للمراجعة البشرية |

## ج. كيف تستورد برنامج P6

1. من تبويب البرنامج اختر **XER** إذا كان الملف صادرًا بصيغة XER، أو افتح لوحة P6 لاختيار **Primavera XML**.
2. انتظر اكتمال القراءة ثم راجع العدد المعروض للأنشطة والعلاقات والتقاويم وWBS والموارد إن وجدت.
3. افتح الشبكة وتأكد من أن النشاطات الحرجة والأسماء وتاريخ الإكمال تتفق مع نسخة المشروع. عند الاختلاف، أوقف التحليل وعد إلى محرر P6 للتحقق من تاريخ البيانات والتقويم والفلترات.
4. احفظ نسخة JSON من البرنامج داخل التطبيق قبل إدراج أي Fragnet. تعد هذه النسخة مرجعاً يمكن تنزيله واستعادته.

## د. إنشاء Fragnet صحيح

الـ Fragnet ليس وصفاً نصياً للتأخير. هو نموذج لأنشطة الحدث وعلاقاته داخل شبكة البرنامج. اختر العلاقة التي كان سيستمر منطق البرنامج عبرها لولا الحدث، ثم أضف النشاط المؤخر بين predecessor وsuccessor. اكتب الوصف والسبب وتاريخ الوقوع ومدة لها مصدر. لا تستخدم مدة «تقديرية» دون تمييزها كمؤقتة.

## هـ. التعامل مع الأثر المالي

يعرض التبويب تكلفة يومية وتعرض تمديد، مفصولاً حسب نوع المورد. هذا رقم تشغيلي يساعد على ترتيب الملف، وليس مطالبة مالية نهائية. إذا ظهر «لا توجد إسنادات في نطاق الحدث»، فراجع مطابقة `activityId` بين برنامج P6 والـ Fragnet، ثم أعد استيراد ملف صحيح أو وثق سبب عدم توافر المورد.

## و. إنشاء Notice ومراجعته

استخدم زر **إنشاء مسودة تلقائية** بعد اختيار الحدث؛ ينشئ التطبيق مسودة واحدة قابلة للرجوع ولا يرسل أي بريد. ثم أدخل بيانات المرسل والمستلم وبند العقد وتاريخ العلم وموعد الإشعار وحدد الأدلة المرجعية. لا تغيّر الحالة إلى «مرسل» إلا بعد الإرسال الفعلي وفق إجراء الشركة؛ التطبيق لا يثبت التسليم الخارجي من تلقاء نفسه.

## ز. الاعتماد الإلكتروني

المسار هو: **مسودة → التخطيط → العقود → مدير المطالبات → جاهزة للتصدير**. يعيّن مالك المطالبة مراجعاً لكل مرحلة. لا يحق للمراجع اتخاذ قرار بوابة غير مخصصة له. اكتب تعليقاً واضحاً عند الرفض أو التعليق، لأن التعليق والقرار والتاريخ تبقى في سجل التدقيق.

## ح. قائمة فحص ما قبل التقرير

- [ ] نسخة البرنامج موثقة وتاريخ بياناتها معلوم.
- [ ] التقويم والعطل والعلاقات تمت مراجعتها.
- [ ] لكل Fragnet تاريخ وسبب ومدة وموقع شبكة واضح.
- [ ] نتيجة TIA مفهومة مع أي تزامن أو عائمة.
- [ ] كل قيمة مالية مرتبطة بمورد/نشاط أو مذكور سبب عدم الربط.
- [ ] Notice يتضمن بند العقد والمواعيد والأدلة.
- [ ] مراحل المراجعة وتعيينات المراجعين وقراراتهم مكتملة.
- [ ] تمت معاينة DOCX/PDF قبل مشاركته خارج الفريق.

## ط. حل المشكلات الشائعة

| العرض | السبب المحتمل | الإجراء الصحيح |
|---|---|---|
| فشل حساب CPM | حلقة علاقات أو نشاط مفقود | راجع العلاقة المشار إليها ثم صحح ملف المصدر |
| أثر زمني صفر | الحدث داخل عائمة أو Fragnet غير موصول | افحص موقع الحدث ومنطق الدخول/الخروج |
| موارد صفر | اختلاف معرفات النشاط | استخدم معرفات P6 الفعلية وأعد الاستيراد |
| لا يمكن اتخاذ قرار | لم تعيّن بوابة المراجعة لهذا الحساب | اطلب من مالك المطالبة تعيينك |
| Notice متأخر | تاريخ العلم أو مدة العقد غير صحيحين | راجع العقد؛ لا تعدّل التاريخ لإخفاء الواقع |
