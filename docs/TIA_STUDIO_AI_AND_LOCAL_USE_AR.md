# الذكاء الاصطناعي والتشغيل المحلي — بيان شفاف

## هل يعمل البرنامج بالذكاء الاصطناعي؟

**لا.** الحسابات الأساسية في النسخة الحالية ليست صادرة عن نموذج ذكاء اصطناعي. محرك CPM وTIA، وقراءة XER/XML، وانتقاء إسنادات الموارد، ومعادلة التعرض المالي، والسرد المعياري للتقرير هي أكواد TypeScript وقواعد حتمية قابلة للاختبار. تعطي المدخلات نفسها المخرجات نفسها ما لم تتغير البيانات أو الإعدادات.

| الوظيفة | طريقة التنفيذ الحالية | مكان المعالجة |
|---|---|---|
| CPM وTIA وFragnet | خوارزميات TypeScript | المتصفح |
| XER/XML وCSV وJSON | محللات TypeScript | المتصفح |
| السرد الفني | قالب نصي مبني على نتيجة التحليل | المتصفح |
| الأثر المالي | معادلة موارد وتكلفة محددة | المتصفح |
| الأدلة وNotices والاعتماد | tRPC + قاعدة بيانات + تخزين ملفات | الخادم والحساب المسجل |

لا يوجد استدعاء لخدمة LLM أو إرسال ملف P6 إلى نموذج لغوي ضمن الوظائف الحالية. إذا أضيف لاحقاً مساعد ذكاء اصطناعي لاقتراح السرد أو اكتشاف التناقضات، فيجب أن يكون اختيارياً، وأن يوضح نوع البيانات المرسلة، وأن يطلب موافقة صريحة، وألا يحل محل نتيجة محرك CPM أو قرار المراجع.

## التشغيل من المتصفح مقابل التشغيل المحلي

الحسابات والتحليل يمكن أن تنفذ في المتصفح بعد تحميل التطبيق. أما ميزات الحفظ متعدد الجلسات ورفع الأدلة وNotices والاعتماد تتطلب خادماً وقاعدة بيانات وحساباً مسجلاً. لذلك لا يصح وصف النسخة الكاملة بأنها «مفصولة كلياً عن الإنترنت» ما لم يشغّل المستخدم نسخة محلية من الخادم وقاعدة البيانات والتخزين.

### وضع PWA والعمل دون اتصال

يمكن تثبيت واجهة TIA Studio كتطبيق ويب تقدمي **PWA** من متصفح يدعم التثبيت بعد فتح الموقع عبر اتصال آمن. يحفظ عامل الخدمة ملفات الواجهة الأساسية حتى يمكن فتح شاشة التطبيق لاحقاً **دون اتصال** في حدود ما سبق تحميله. لا يجعل ذلك قاعدة البيانات أو الحسابات أو تخزين الأدلة متاحاً دون اتصال؛ لذلك يجب إتمام أي حفظ أو رفع أو اعتماد عند توفر اتصال بالخادم، أو تشغيل المكونات الخلفية محلياً داخل شبكة المؤسسة.

### مساران محليان

1. **وضع التحليل المحلي:** تنزيل حزمة المصدر وتشغيل الواجهة، ثم استيراد XER/XML وحفظ البرامج والتحليل كملفات JSON. هذا يكفي للحسابات الأساسية دون رفع ملف P6 إلى خدمة AI.
2. **وضع محلي كامل:** تشغيل الخادم وقاعدة بيانات MySQL/TiDB وتخزين كائنات متوافق مع S3 محلياً. عندها تعمل الأدلة وNotices والمراجعة داخل شبكة المؤسسة وفق إعدادات المسؤول.

## متطلبات التشغيل المحلي للمطور

| المتطلب | الغرض |
|---|---|
| Node.js 22 أو أحدث مناسب | تشغيل الواجهة والخادم |
| pnpm | تثبيت الحزم وتشغيل الاختبارات |
| MySQL أو TiDB | سجلات الأدلة والموارد وNotices والاعتماد |
| متغير `DATABASE_URL` | اتصال قاعدة البيانات |
| مزود OAuth أو بديل مصادق عليه | جلسات المستخدمين وحماية المسارات |
| تخزين S3 متوافق | بايتات ملفات الأدلة، وليس قاعدة البيانات |

بعد فك حزمة المصدر، يثبت المطور الحزم، يحدد متغيرات البيئة، يطبق ترحيلات Drizzle، ثم يشغل `pnpm test` و`pnpm dev`. يجب عدم وضع مفاتيح حقيقية داخل ملفات المصدر أو حزمة مشاركة عامة.

## ما سيتم تضمينه في حزمة التنزيل

ستحتوي حزمة المصدر على كود التطبيق، والمخطط والترحيلات، وأدلة Markdown، وأمثلة قابلة للاستيراد، وملف تعليمات للتشغيل. لا تتضمن مفاتيح أو أدلة مستخدمين أو بيانات قاعدة إنتاج أو ملفات مرفوعة.
